# Rank Rush

8-wide endless chess expedition. Start with a king and a knight. Capture to grow the army. Outrun the wake.

**Play:** https://benjaminBrynildsen.github.io/rank-rush/

Tap a piece, tap a square. King or knight captures recruit that piece at the rear. A pawn arrives every 8 moves. The board behind you collapses every 3 moves.
